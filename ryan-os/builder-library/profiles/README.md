# Builder Profiles

Real builder profiles go here, one JSON file per builder. The engine loads
every `*.json` in this directory (files starting with `_` are skipped).

This directory is intentionally empty apart from this README — populating it is
a Class A data task and the highest-value next step. See `../README.md` for how
to add a builder, and `../_TEMPLATE.builder.json` to start from.

Nothing here yet means every builder reads as **new**: 30% margin, Lennox custom
default, everything flagged LOW. The system still works — that is the point of
the defaults — it is just doing it with the least possible information.
